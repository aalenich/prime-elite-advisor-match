Ограничения

Модель обучена на искусственно сформированных оценках соответствия. Результаты не являются доказательством эффективности на реальных банковских данных. Совпадение интересов — вспомогательный критерий; финансовые компетенции и ограничения по доступности важнее.

Оценка качества проведена с разделением по клиентам, а не по отдельным парам. При назначении проверяется сегмент, язык общения и свободная ёмкость портфеля. Приложение работает локально.

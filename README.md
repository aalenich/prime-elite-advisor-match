# Prime & Elite — Advisor Match

Учебный прототип ML-системы подбора персонального менеджера состоятельному клиенту банка. **Все данные синтетические.**

## Запуск

1. Установите Python 3.10+.
2. В терминале перейдите в папку проекта.
3. Установите зависимости: `python -m pip install -r requirements.txt`
4. Запустите: `python server.py`
5. Откройте **http://localhost:8000** в браузере.

Обученная модель уже лежит в `model/matcher.cbm`. Для повторного обучения: `python train.py`.

## Функции

- Генерация и редактирование профиля нового клиента (Prime / Elite).
- CatBoost оценивает пары с доступными менеджерами своего сегмента, возвращает ТОП-3.
- При подтверждении назначения меняется текущая нагрузка и сохраняется история в `data/live_assignments.json`.
- Каталог менеджеров с компетенциями, фильтрами и загрузкой.
- Дашборд с загрузкой по сегментам и регионам, метриками ML и назначениями.
- Сброс демонстрационных назначений на вкладке аналитики.

## Данные и ограничения

100 менеджеров, 5000 клиентов, 50000 обучающих пар, 3500 исходных назначений. `match_score` создан симулятором, **не отражает реальную удовлетворённость клиентов**. Модель обучается на синтетических оценках и не проверена на реальном банковском процессе. MAE и NDCG@3 рассчитаны на отложенных клиентах. Базовая модель — ручная формула; качество модели на реальных данных неизвестно.

Ранжирование проводится только среди менеджеров того же сегмента, со свободными местами и совместимым языком. Нагрузка обновляется при назначении. Показатели нагрузки учитываются в модели. Объяснения в интерфейсе — фактические совпадения признаков, **не SHAP-атрибуции**.

Сервис локальный демонстрационный: нет авторизации, конкурентного промышленного хранилища, разграничения доступа, проверки справедливости рекомендаций. Не использовать в реальном банке без доработки и валидации.
